### Dynamic Route Optimizer

**Academic Project | C++, Algorithms, Graphs, Data Structures**

A dynamic route optimizer on a hexagonal grid using weighted graphs and Dijkstra's algorithm, with a Min Heap for priority-queue operations and Hash Table caching to optimize repeated route queries.

**Key aspects:**

* Hexagonal grid representation.
* Graph-based modeling with Dijkstra.
* Min Heap and Hash Table optimization.
* Logistics optimization.

### ROS 2 Odometry — First Robotics Project

**Academic Project | ROS 2, C++, Odometry, TF, RViz2**

Odometry system for a skid-steering mobile robot, estimating trajectory from wheel and robot-status data: experimental calibration of the wheel-to-velocity factor and effective wheelbase against ground-truth TF data, ROS 2 nodes for estimation, TF error analysis, trajectory visualization and reset, evaluation on travelled distance and positional error.

### ROS 2 Mapping & Autonomous Navigation — Second Robotics Project

**Academic Project | ROS 2, C++, Nav2, SLAM, AMCL, Stage, RViz2**

Complete pipeline covering 2D environment mapping and autonomous navigation: occupancy-grid maps from ROS 2 bag files integrated into a Nav2 stack, AMCL with global/local costmaps and DWB controller, custom C++ goal-publisher node via NavigateToPose, Stage + RViz2 simulation and evaluation.

### Hardware Module for Task List Management

**Academic Project | VHDL, FPGA, RAM, FSM**

VHDL hardware module managing an ordered task list in external RAM: finite-state machines for insertion, removal, priority management, clearing and memory operations, verified by behavioral simulation and synthesized with Xilinx Vivado.
